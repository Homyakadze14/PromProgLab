# Лабораторная работа 2: Музыкальный плейлист (Playlist)

## Выбор структуры данных:
Для реализации плейлиста использован динамический массив

### Почему был выбран динамический массив:
- Нужен быстрый доступ по индексу (O(1)) для навигации
- Перемешивание (O(n)), реализуется через rand.Shuffle
- Добавление в конец (O(1)). Плейлист чаще пополняется, чем удаляется из середины
- Нужна минимальная дополнительная память (нет дополнительных ссылок)
